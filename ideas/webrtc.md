### 3. **Peer-to-Peer File Sharing App**

- Features: Direct peer-to-peer file transfer, drag-and-drop UI, file integrity checks.
- Technologies: WebRTC Data Channels, React, TypeScript, Node.js.
- Description: Create an app that allows users to share files directly without any server storage. Implement a drag-and-drop interface for ease of use.
