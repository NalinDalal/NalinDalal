# Pre AI Vibe Coding Projects

### 1. **Digital Garden / Personal Wiki**

- **Stack:** Next.js / Astro + Markdown or SQLite
- **Why:** Organize your knowledge, thoughts, book notes, and projects in a beautiful format. Like a Notion alternative you own.
- **Twist:** Add backlinks and a graph view like [Obsidian.md](https://obsidian.md/).

### 2. **Music Visualizer**

- **Stack:** Web Audio API + Canvas/WebGL
- **Why:** Express your favorite songs visually. Sync visuals to beat drops.
- **Twist:** Make a custom skin/theme for different genres.

### 3. **Terminal Dashboard**

- **Stack:** Node.js (Ink) or Python (curses)
- **Why:** Build a hacker-style terminal that shows weather, GitHub activity, stock prices, todo list, and your custom RSS feed.
- **Twist:** Make it multiplayer via sockets for friend group productivity.

### 4. **Code Notebook / REPL Sandbox**

- **Stack:** React + Monaco Editor + iframe sandboxing
- **Why:** Make your own JS or Python playground like Replit or Jupyter.
- **Twist:** Add versioned snippets, execution history, or multiplayer collab.

### 5. **Custom OS-like Web Desktop**

- **Stack:** React or Svelte + drag-n-drop windows
- **Why:** Build your own "web OS" with apps like Notepad, Terminal, Weather, Calculator.
- **Twist:** Add login, themes, and virtual desktop wallpapers.

### 6. **Pixel Art Game / Engine**

- **Stack:** Kaboom.js / Phaser / Godot (if native)
- **Why:** Making 2D games is an art form. Story + mechanics + music.
- **Twist:** Build a level editor, shareable level codes, or speedrun timer.

### 7. **Old-School Forum / Message Board**

- **Stack:** Node/Bun + SQLite or Rust + Actix
- **Why:** Bring back the early-2000s BBS-style boards. Add badges, Markdown posts, and admin tools.
- **Twist:** Add in-thread real-time chat or RSS subscriptions.

### 8. **Zen Productivity Suite**

- **Stack:** Electron / Tauri
- **Why:** Build tools like Pomodoro Timer, habit tracker, focus music player.
- **Twist:** Self-hosted with sync across devices, or powered by local-only data.

### 9. **PacMan**

- **Stack:** CPP
- **Why:** Learn internals, gui, basic game development

## Meta-Project Ideas

- **Your own programming language** (Tiny Lisp or stack-based)
- **Your own text editor** (like VS Code lite)
- **A digital bookshelf / reading tracker**
- **Creative writing tool with mood board / character sheets**
- **Digital arcade / showcase of all your projects**

### 1. **Live Tools / Visualizations**

- **Code Playground** — Like CodePen or Replit but limited in scope (e.g. JS, CSS sandbox, AST visualizer).
- **Real-Time Terminal Emulator in Browser** — With WebSocket + PTY backend.
- **Graph Algorithms Visualizer** — Dijkstra, A*, DFS/BFS — all animated beautifully.
- **Data Structures Visualizer** — AVL trees, heaps, hashmaps. Emphasize clean animations and controls.

> Why? Sharpens algo/ds + gives interactive feedback + perfect for AI augmentation later (e.g., explain this tree?).

### 2. **Games with Systems Thinking**

- **Tower Defense Game** — With editable logic or level editor.
- **Physics Sandbox** — Collisions, gravity, particles — use Matter.js or Rapier (Rust).
- **Multiplayer Chess / Go / Sokoban** — Implement server logic too.
- **Roguelike Engine** — Procedural generation, tilemaps, turn-based logic.

> You learn rendering, game logic, networking, and polish. Later you can plug in AI players, narration, or level generation.

### 3. **Infra + Real-Time Systems**

- **Redis Clone** — Simple in-memory DB with commands, pub/sub, persistence.
- **HTTP Proxy with Logging** — Log, cache, replay requests, add latency.
- **WebRTC P2P File Share or Screen Share** — Like Snapdrop or tiny Google Meet.
- **Live Collaborative Editor** — CRDT or OT-based, even for simple markdown.

> Shows you know systems and real-time. Later: add AI to autocomplete, summarize, replay history, etc.

## Bonus: How to Build for Maximum Vibes

- Use **Tailwind + shadcn/ui** or **custom CSS** — clean UI matters.
- Add **Framer Motion** or smooth transitions.
- Add a **custom domain + dark mode + easter eggs**.
- Use **Bun**, **Rust**, or **Go** for servers. Lean into performance.
- Add **live logs, themes, or music** for flair.

- BFS maze solver
- DFS sudoku solver
- Dijkstra algo map
